# App templates

Apps start from `app/`: Vite + React + shadcn/ui + Tailwind, themed by the design system (`modules/apps-platform/design-system/`), served by a dependency-free Node server, with the patterns in place (sidebar and bottom-bar shell, filters that apply in place and live in the URL, a sortable table, details in a sheet, toasts, every state, a strict CSP) and a `/catalog` page. `app/aidenhq-identity.mjs` is the identity middleware every app copies unchanged: it wraps the app's whole handler and gives it `req.user` (docs/design/app-identity.md; `scripts/sync-shared.mjs` keeps it equal to `services/shared/`). CI comes from `ci/`. Every app's health URL answers JSON `{ok: true, checks: []}`: `checks` lists the rules about the app's own data it can evaluate (`{name, ok, count, sample}`; empty by default), which reach the app's owner as quality findings, never as outages (docs/configuration.md, Quality checks).
