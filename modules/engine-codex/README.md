# engine-codex

## What it does

Codex as the engine for runner jobs, on OpenRouter models through the model gateway, in an agent computer
(`codex-openrouter`). It is how the Engineer writes code.

## Connect

Nothing to connect. The models come from `models-openrouter`.

## What agents get

No tools. It provides the `engine` role that `engineering` requires.

## New installs

In the default bundle. It runs only when an Engineer job starts.
