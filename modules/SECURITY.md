# Security

Please report vulnerabilities privately. Do not open a public issue or PR.

Use GitHub's private reporting: the "Security" tab of this repo, then "Report a vulnerability". For anything that
affects the kernel, report it on [Aiden-HQ/AidenHQ](https://github.com/Aiden-HQ/AidenHQ) the same way.

Include what you found, how to reproduce it and which module is affected. Reports get a reply from the maintainers;
fixes ship as a normal PR once a patch is ready.

Supply-chain rules (pinned dependencies, 7-day minimum age) are in the product repo's
[CONTRIBUTING.md](https://github.com/Aiden-HQ/AidenHQ/blob/main/CONTRIBUTING.md).
