# Inbox scan

The Gmail label `Aiden` marks a thread as a task. Your one Gmail write is `gmail_label` removing `Aiden` from a thread whose task the owner closed, so the label marks open work only.

1. `gmail_search` `label:Aiden`, `max_results` 50, no `account` (all accounts). Group by `account` and `thread_id`. An account with an `error` or exactly 50 messages has an incomplete list.
2. **Label removed:** `task_list` `label: "email"`, `limit: 200` (the tool's maximum: answered tasks stay open), `task_get` each for its `source:gmail:label:<thread_id>` marker and `Account:` line. Read each task's comments with `task_comments` (`limit: 100`, the tool's maximum) and compare the account's list with the latest "Label removed" or "Label restored" line. A thread absent from step 1 whose account listed completely lost its label and has no removal line since any restore: `task_comment` on that task "Label removed in Gmail — left open for the owner to close."; a thread back in step 1 after a removal line gets the one "Label restored in Gmail — left open for the owner." Otherwise comment nothing. These tasks are the owner's: never finish one; a `task_finish` with `issue` on it is refused ("only this job's own task is finished here"). Incomplete accounts keep their tasks.
3. **Create:** `gmail_read_thread` (its `account`), then `task_create`: `marker: source:gmail:label:<thread_id>`, `dedupe_closed: true`, `labels: ["todo", "email"]`, `title` what the owner needs to do ("Read: <topic>" if informational), `priority` `high` for a deadline today or tomorrow or a blocker, `low` if plainly FYI, else `medium`, `description` your mission's format with `Type: Email`, `Account:`, `From:`, `Subject:`, `Received:` (newest message), `Link:` (the result's `link`, unchanged), Reason starting "Labelled `Aiden` in Gmail." A `deduplicated` answer: `task_get` it. Closed (done or cancelled): the owner finished it, so `gmail_label` (`thread_id`, its `account`, `remove: ["Aiden"]`) and nothing else. On an open duplicate with a message newer than the task's creation (compare times; replies already in the task don't count): a one-sentence `task_comment`, and `task_update` the priority if warranted.
4. `task_finish` on your run task with a count line, e.g. "Labelled: 3 threads across 2 accounts (1 new task); marked answered 1 removed label (left open for the owner); cleared the label from 1 closed task".
