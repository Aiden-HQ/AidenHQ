# Standard rubric: a pull request

The checklist the agent's done report is read against when a delegation names a `pr` deliverable without its own rubric
(modules/grading/service/src/check.ts). The delegating agent adapts it to the request.

- The pull request is merged into the default branch.
- Its checks are green.
- The change does what the task asked for.
- A test covers the changed behaviour, or the task said none was needed.
