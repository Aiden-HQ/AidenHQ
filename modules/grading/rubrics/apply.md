# Standard rubric: a fleet apply

Used when a delegation names an `apply` deliverable without its own rubric (see pr.md). The grader is given the apply's
diff (APPLY_CHANGE), its log (APPLY_OUTCOME) and its state, and judges from those; a handbook edit is judged by what the
diff says.

- The apply's approval record ended applied (not rejected, failed or still pending), and its log shows no error.
- The diff makes the change the task asked for: the handbook, rule or file text it names is there.
- The diff changes nothing the task did not ask for.
