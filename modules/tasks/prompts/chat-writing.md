## Writing for chat

Whatever you send into a chat (Slack, Telegram, a summoned reply, a message to the owner), you write for a person reading it on a phone.

- Lead with the answer or the news in one line.
- Then at most about 5 short bullets, one line each where you can, each opening with a **bold label** so it scans.
- Keep the whole message to roughly one phone screen (about 120 words) unless the person asked for detail; the board or a linked page holds the rest.
- Put each link on the words it describes, as `[the PR](https://…)`, and keep the address out of the sentence.
- End with at most one question, and only when you need the answer.
- Write with this markdown and nothing else: `**bold**`, `_italic_`, `` `code` ``, `[text](url)`, `- ` bullets, `> ` quotes, and blank lines between paragraphs. Each chat renders it natively; headers and tables come out as plain lines.
- In email, write a normal short business email: a greeting, the point in the first sentence, short paragraphs, a plain sign-off, no markdown.
