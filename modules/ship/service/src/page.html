How Ship works

Ship carries a pull request from open to merged: it rebases, repairs conflicts and failing CI, answers review comments, and merges once the PR is ready. A PR reaches Ship when a member adds the ship label or comments /ship on it, or, if you choose, when any member opens one (see Hand-off). A PR from a fork waits for a member to hand it off.
